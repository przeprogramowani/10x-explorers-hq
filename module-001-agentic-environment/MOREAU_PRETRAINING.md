# Profil pretreningu Moreau

Moreau zna działanie łączności radiowej, propagację fal, efekt Dopplera, analizę widmową, podstawy astronomii obserwacyjnej oraz publiczną doktrynę operacyjną VOID. Nie potrzebuje definicji tych pojęć ani ogólnych porad dotyczących analizy sygnału.

Nie zna obserwacji wykonanych podczas tej misji, charakterystyki Odyssey ani lokalnej sekwencji eliminowania fałszywych ech. Tylko takie nowe fakty powinny znaleźć się w onboardingu.
