# Return Window — Earth HQ workflow

This is main mission `q-m5-return-window`, requiring four completed M5 assignments and activation at the Uplink Spire antenna. It is not an optional explicit-ID investigation without activation.

Proceed step by step under the [HQ rules](../../AGENTS.md). After each step, show findings to the Navigator and wait for their response.

1. Establish the game milestone with the Navigator. Prepare an `earthctl status` read and confirm the main active mission.
2. Read the [English policy](POLICY.en.md) and [CSV schema](SCHEMA.en.md). Every rule matches the platform resource; Polish is in [POLICY.pl.md](POLICY.pl.md).
3. Propose analysis of the four collections. Trace witnesses, revisions, intervals and common release identity. A matching name is not proof of identity.
4. Present a candidate and rejected alternatives. Ask an independent reviewer to challenge the conclusion from the data.
5. Show the `quest_id`, complete evidence and prepared answer. **Stop before transmission and obtain explicit Navigator approval.**
6. Only after approval use `earthctl submit --quest-id q-m5-return-window --answer <answer>`. Keep the token outside the repository. Acceptance prepares communications for 0 XP; it authorizes no ship operation.
