# Okno powrotu — praca w Earth HQ

To główna misja `q-m5-return-window`, wymagająca czterech ukończonych zadań M5 i aktywacji przy antenie Wieży Łącza. Nie jest misją opcjonalną z jawnym ID bez aktywacji.

Prowadź pracę stopniowo według [zasad HQ](../../AGENTS.md). Po każdym kroku pokaż Nawigatorowi ustalenia i poczekaj na jego reakcję.

1. Ustal z Nawigatorem etap gry. Przygotuj odczyt `earthctl status` i potwierdź główną aktywną misję.
2. Przeczytaj [politykę PL](POLICY.pl.md) i [schemat CSV](SCHEMA.pl.md). Wszystkie reguły są identyczne z zasobem platformy; wersja angielska jest w [POLICY.en.md](POLICY.en.md).
3. Zaproponuj analizę czterech kolekcji. Prześledź świadków, rewizje, przedziały i wspólną tożsamość wydania. Nie uznawaj nazwiska za dowód tożsamości.
4. Przedstaw kandydata i odrzucenia. Poproś niezależnego recenzenta o próbę obalenia wniosku na podstawie danych.
5. Pokaż `quest_id`, wszystkie dowody i gotową odpowiedź. **Zatrzymaj się przed transmisją i uzyskaj jawne potwierdzenie Nawigatora.**
6. Dopiero po potwierdzeniu użyj `earthctl submit --quest-id q-m5-return-window --answer <odpowiedz>`. Token pozostaje poza repozytorium. Przyjęcie przygotowuje łączność za 0 XP; nie zezwala na żadną operację statku.
